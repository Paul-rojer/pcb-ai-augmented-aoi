live_help Troubleshooting

Network latency anomalies expand_more
Verify that your local laboratory gateway is configured for 10Gbps throughput. Check that packet priority is set to 'High' for the AOI PRO inference streams.
Inference lagging (Critical) expand_more
This typically indicates GPU thermal throttling. Inspect cooling intake filters and ensure environmental temperature is below 24°C (75°F).
False-Positive drift expand_more
Perform a recalibration of the optical sensor using the standard 12-point reference grid. Drift often occurs after intense vibration cycles.
API Authorization errors expand_more
Ensure your Bearer tokens are rotated every 72 hours. Check the engineering dashboard for expiring credentials.
